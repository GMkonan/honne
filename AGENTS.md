## AI collaboration

Honne uses an owner-led, lightweight AI collaboration model. Read `docs/agents/working-agreement.md` before making changes. Use GitHub Issues only when durable product context or coordination is useful; small coherent changes do not require tracker ceremony.

Conversation language: pt-BR (source of truth: `docs/agents/language.md`). Git and GitHub artifacts are written in English. Learned project rules should be recorded in the relevant project guideline.
